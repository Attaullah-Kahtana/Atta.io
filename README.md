### 2. Structure-Based In Silico Drug Design

Undergraduate research project focused on structure-based drug design targeting the **InhA enzyme of multidrug-resistant Mycobacterium tuberculosis**.

The workflow included:

* Protein structure preparation and validation
* Active-site analysis
* Virtual screening
* Drug-likeness analysis
* ADMET profiling
* hERG toxicity prediction
* Molecular docking
* Molecular dynamics simulation

**Tools:**

* Discovery Studio
* CASTp
* SwissADME
* PyRx
* AutoDock Vina
* GROMACS

### 3. AI & ML-Based hERG Prediction Model

A machine-learning project focused on predicting **hERG-related cardiotoxicity from chemical structures**.

The project includes:

* Chemical structure cleaning
* Molecular standardization
* Descriptor calculation
* Molecular fingerprints
* Feature engineering
* Machine-learning model development
* Model evaluation
* Explainable AI

**Technologies:**

* Python
* RDKit
* Scikit-learn
* Machine Learning
* Cheminformatics
* Molecular Descriptors
* Morgan Fingerprints
* SHAP

### 4. Early Sepsis Risk Predictor

A machine-learning project aimed at identifying the risk of sepsis in ICU patients before clinical onset.

The project uses the **PhysioNet Challenge 2019 dataset** and explores machine-learning approaches for early sepsis prediction.

**Technologies:**

* Python
* Pandas
* XGBoost
* SHAP
* Machine Learning
* Clinical Data Analysis
